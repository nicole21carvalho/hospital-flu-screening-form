# 🏥 Formulário Hospitalar

Site de um hospital com formulário para **identificação inicial de sintomas gripais**, feito com HTML e Bootstrap.

## ✨ Páginas

- 🏠 **Início (`index.html`):** barra de navegação e imagem do hospital
- 📝 **Cadastro (`cadastro.html`):** nome, CPF, RG, doenças pré-existentes e sintomas (febre, dor de garganta, tosse e dor no corpo)
- 🔐 **Home (`Home.html`):** formulário de login com e-mail e senha

## 🛠️ Tecnologias

HTML · CSS · Bootstrap 5

## 🚀 Como executar

Baixe o repositório e abra o `index.html` no navegador.
